# Tiered upgrade approach for homelab Docker services

When executing Docker upgrades, tier them:
1. **Floating tags** (`:latest`, `:main`, `:stable`) — safe `docker compose pull && up -d`, no file changes to commit
2. **Pinned major versions** (`:v8`, `:14`) — check upstream for new major, bump compose/.env, commit the change
3. **Cross-machine coordinated** (immich) — REQUIEM API first, then GENESIS workers; both must be same version
4. **Locally built** — rebuild from Dockerfile, tag and redeploy

Smoke test each service before moving on. Give 2–3 min to come up, check logs if unsure.
