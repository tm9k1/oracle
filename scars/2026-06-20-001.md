# Claude Code permission bootstrap deadlock via Discord

When Oracle spawns Claude Code sessions via `oracle_bot.py` (the `claude -p` subprocess approach), those sessions run without `--dangerously-skip-permissions`. All file writes and SSH commands are blocked. There's no UI to approve them — it's a headless Discord bot. Result: complete deadlock.

**Fix**: Add `--dangerously-skip-permissions` to the `cmd` list in `oracle_bot.py:87`.
**Bootstrap problem**: Can't apply the fix from within the blocked session either.
**Solution**: Apply the fix manually on the Pi, or run Claude Code CLI with `--dangerously-skip-permissions` from the start.
