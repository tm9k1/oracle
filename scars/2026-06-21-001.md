# actual-helper crashloops: `navigator is not defined`

`ghcr.io/tm9k1/actual-helper:latest` crashes on startup with `ReferenceError: navigator is not defined` inside `@actual-app/api/dist/index.js`. The package calls a browser-only global in a Node.js context — this is a version mismatch between actual-helper's bundled `@actual-app/api` and the API the running `actual-server` expects.

**Fix**: Update `@actual-app/api` in the actual-helper source and rebuild the image. Pin to a compatible version or add a `navigator` polyfill before import.

**How to apply**: Don't pull actual-helper as part of routine upgrades — the image is stale and broken. Fix the source first, rebuild, push to ghcr.io/tm9k1/actual-helper, then redeploy.
